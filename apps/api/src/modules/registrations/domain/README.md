# Dominio

entities contiene vocabulario y estados del registro; policies contiene reglas sobre vigencia, verificación y archivos admitidos. Estos archivos no importan Nest, Prisma ni contratos HTTP.

Un permiso de operación no reemplaza la propiedad del expediente. Los repositorios deben restringir las consultas a las carreras del actor verificado. Los identificadores recibidos nunca otorgan acceso por sí solos.
