# HU-E5-17 · Evidencia de Vacantes

La suite HTTP usa el controlador y servicio de Vacantes de epic3, peticiones Supertest, un actor de prueba y un sustituto de Prisma en memoria. Comprueba respuestas HTTP y operaciones de persistencia. La autenticación y la concurrencia de PostgreSQL quedan fuera de esta suite.

| Criterio | Cobertura |
| --- | --- |
| CA-01 a CA-03 | Alta, segunda solicitud idempotente, perfil incompleto, vacante cerrada y pausada |
| CA-04 y CA-05 | Aislamiento HTTP con dos titulados y dos postulaciones en ambas consultas y campos públicos de la oferta |
| CA-06 | Listado y cambio de etapa con acceso a la empresa y con acceso denegado |
| CA-07 | Pendiente de la integración del servicio real de HU-10 de epic1 |
| CA-08 | Tres pares sintéticos perfil-vacante y evaluador de orden relativo en instrumentación de pruebas. Umbral definido en 3/3 comparaciones estrictas. Pendiente la ejecución con el motor real |
| CA-09 | Servicio de postulaciones, carga, error y reintento en la oferta, desglose ausente y habilidades recibidas |
| CA-10 a CA-12 | Comprobaciones ordinarias con APP_ENV=test. Dobles explícitos en las suites nuevas. Registrar cada defecto con criterio, caso reproducible y HU responsable |

## Integración pendiente

Al incorporar HU-10, verificar el DTO y el permiso requerido por POST /api/v1/affinity/batch, los identificadores para titulado y vacante y las unidades de percentage. Crear las entidades sintéticas de vacancyMatchingCases dentro de la base temporal del helper de integración, invocar el endpoint real y comprobar status, percentage y comparison para cada par. Ejecutar únicamente con TEST_DATABASE_URL de PostgreSQL local desechable. Entregar los tres porcentajes observados a passesMatchingRegression y exigir un resultado verdadero. El test del evaluador comprueba el cálculo de la métrica. El resultado del motor queda pendiente.

Para reproducir los controles ordinarios, usar Node 22.22.1, pnpm 9, APP_ENV=test y ejecutar pnpm lint, pnpm test y pnpm build desde la raíz. Los resultados de la ejecución se registran en la PR.
