# Matriz de Verificación: Consulta de Estado por Correo (HU-18 · Tarea 18.4)

Matriz de pruebas de integración para la consulta pública de estado de solicitudes de titulación vía correo electrónico (CA-18.2 a CA-18.7).

- **Endpoint público:** `POST /registrations/status-query`
- **Mensaje genérico (CA-18.2):** `"Si la dirección de correo corresponde a una solicitud registrada, se ha enviado la información sobre su estado."`
- **Código HTTP:** `202 Accepted`
- **Prueba automatizada de referencia:** `apps/api/test/integration/status-query.e2e-spec.ts`

---
